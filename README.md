# Employee Management System Pro 🚀

A robust, enterprise-level solution for managing employee data, attendance, and salaries. Built for high performance and reliability.

## ✨ Key Features
- **Professional GUI:** Crafted using PyQt6 for a modern and sleek user experience.
- **Background Verification:** Implements Python `threading` for continuous attendance monitoring without blocking the main UI.
- **Smart Notifications:** Automated email alerts for absences or late exits using `SMTP`.
- **Database Integration:** Secure and structured data handling with `SQLite`.
- **Clean Architecture:** Organized code following best practices for scalability.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **UI Framework:** PyQt6
- **Database:** SQLite
- **Concurrency:** Threading
- **Communication:** SMTP / MIMEText

## 🚀 How it Works
This system allows managers to register employees, track attendance in real-time, and automatically penalize delays through a smart background checker.
